# Huatuo 数据集下载指南

## 方法一：使用自动下载脚本（推荐）

### 步骤 1：打开命令行
在项目目录下打开 PowerShell 或命令提示符

### 步骤 2：运行下载脚本
```powershell
python download_simple.py
```

或者使用原始脚本：
```powershell
python huatuo_datasets.py
```

---

## 方法二：手动下载（如果自动下载失败）

### 步骤 1：访问镜像站
打开浏览器访问：https://hf-mirror.com/FreedomIntelligence

### 步骤 2：下载数据集
下载以下数据集：
1. **huatuo_knowledge_graph_qa** - 知识图谱问答
2. **huatuo_encyclopedia_qa** - 百科问答  
3. **huatuo_consultation_qa** - 问诊问答
4. **huatuo26M-testdatasets** - 测试数据集（6k条）
5. **Huatuo26M-Lite** - 轻量版数据集

### 步骤 3：放置文件
将下载的文件放到项目目录下的 `./data/` 或 `./huatuo_data/` 文件夹中

### 步骤 4：加载本地数据
使用以下代码加载：
```python
from datasets import load_from_disk

# 加载数据集
dataset = load_from_disk('./huatuo_data/FreedomIntelligence_huatuo_knowledge_graph_qa')

# 查看数据
print(dataset)
print(dataset['train'][0])
```

## 常见问题

### Q: 下载超时怎么办？
A: 
1. 检查网络连接
2. 尝试使用代理
3. 改用手动下载方式

### Q: 下载的文件放在哪里？
A: 脚本会自动保存到 `./huatuo_data/` 或 `./data/` 目录下

### Q: 如何查看已下载的数据？
A: 创建一个测试脚本 `test_data.py`：
```python
from datasets import load_from_disk
import os

data_dir = "./huatuo_data"
if os.path.exists(data_dir):
    for item in os.listdir(data_dir):
        if os.path.isdir(os.path.join(data_dir, item)):
            print(f"\n数据集: {item}")
            try:
                ds = load_from_disk(os.path.join(data_dir, item))
                print(f"  分割: {list(ds.keys())}")
                for split in ds:
                    print(f"    {split}: {len(ds[split])} 条")
            except:
                pass
```
