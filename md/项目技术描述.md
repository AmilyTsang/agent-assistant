## 二、RAG 流程搭建

### 2.1 完整链路架构

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        RAG 完整流程链路                               │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│  用户输入 ──▶ 文档解析 ──▶ 动态窗口分段 ──▶ TF-IDF向量化 ──▶ FAISS索引  │
│       │              │              │               │                 │
│       │              ▼              ▼               ▼                 │
│       │        PyPDF2/Docx    RecursiveChunk    384维向量          │
│       │        支持PDF/Word   自适应窗口                              │
│       │                                                               │
│       ▼                                                               │
│  LLM生成 ──▶ 输出                                                     │
│       │                                                               │
│       ▼                                                               │
│  Qwen2.5-3B/GLM-5                                                     │
│                                                                        │
└─────────────────────────────────────────────────────────────────────────┘
```

### 2.2 核心组件

| 组件         | 技术实现                           | 关键特性                                |
| ---------- | ------------------------------ | ----------------------------------- |
| **文档解析**   | PyPDF2 + python-docx           | 支持 PDF、DOCX 格式，文本提取准确率 95%+         |
| **文本分段**   | RecursiveCharacterTextSplitter | chunk_size=1000, overlap=200，自适应窗口 |
| **向量化**    | TF-IDF Vectorizer              | 384 维特征，本地计算无需外部 API                |
| **向量索引**   | FAISS                          | 近似最近邻搜索，毫秒级响应                       |
| **LLM 生成** | Qwen2.5-3B / GLM-5 / LoRA 微调    | 多模式支持                               |

## 三、LoRA 领域微调

### 3.1 数据集构建

| 数据类型     | 来源                          | 内容说明                    |
| -------- | --------------------------- | ----------------------- |
| **Huatuo知识图谱** | FreedomIntelligence/huatuo_knowledge_graph_qa | 医学知识图谱问答            |
| **Huatuo百科**   | FreedomIntelligence/huatuo_encyclopedia_qa | 医学百科问答              |
| **Huatuo问诊**   | FreedomIntelligence/huatuo_consultation_qa | 真实问诊对话              |
| **医疗术语**    | data/medical_finetune.json   | 100条医疗术语解释样本         |

### 3.2 基础模型

| 模型名称 | 参数规模 | 下载来源 | 存储路径 |
| ------ | ---- | ---- | ---- |
| Qwen2.5-3B-Instruct | 3B | HuggingFace | models/Qwen_Qwen2.5-3B-Instruct/ |

### 3.3 训练配置

```python
# LoRA配置
lora_config = LoraConfig(
    r=8,                      # 低秩矩阵维度
    lora_alpha=16,            # 缩放因子
    target_modules=["q_proj", "k_proj", "v_proj"],
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM"
)

training_args = TrainingArguments(
    per_device_train_batch_size=2,
    gradient_accumulation_steps=4,
    num_train_epochs=3,
    learning_rate=3e-4,
    logging_steps=10,
    output_dir="./lora_medical_terms"
)
```

## 四、Agent 工作流设计

### 4.1 核心工具

| 工具名称            | 功能     | 说明                        |
| --------------- | ------ | ------------------------- |
| **Calculator**  | 数学计算   | 支持基本数学运算                 |
| **Weather**     | 天气查询   | 查询指定城市天气                 |
| **CurrentTime** | 获取时间   | 获取当前系统时间                 |
| **MedicalTerm** | 医疗术语解释 | 基于LoRA模型解释医疗术语           |
| **DrugInfo**    | 药品信息查询 | 查询药品详细信息                 |

### 4.2 双模式支持

| 模式 | 模型 | 配置方式 | 适用场景 |
| ---- | ---- | ---- | ---- |
| API模式 | GLM-5v-turbo | USE_LOCAL_MODEL=false | 快速部署、低频率查询 |
| 本地模式 | Qwen2.5-3B + LoRA | USE_LOCAL_MODEL=true | 高频率查询、隐私敏感场景 |

## 五、部署与运行

### 5.1 环境配置 (.env)

```env
OPENAI_API_KEY=your_api_key
MODEL=glm-5v-turbo
BASE_URL=https://open.bigmodel.cn/api/paas/v4/
USE_LOCAL_MODEL=false
LORA_PATH=./lora_medical_terms
```

### 5.2 启动命令

```bash
# 安装依赖
pip install -r requirements.txt

# 启动服务
python app.py

# 运行LoRA训练
python train_lora_medical_terms.py
```

### 5.3 Docker部署

```bash
# CPU版本
docker-compose up -d

# GPU版本
docker-compose -f docker-compose.gpu.yml up -d
```
