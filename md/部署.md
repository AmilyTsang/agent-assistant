## 2. Docker 容器部署（推荐）

### 2.1 环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Docker | 20.10+ | 容器运行时 |
| Docker Compose | 2.0+ | 编排工具 |
| NVIDIA Docker | 可选 | GPU 加速（LoRA 训练/推理） |

### 2.2 创建 Dockerfile

```dockerfile
# 使用 Python 3.9 作为基础镜像
FROM python:3.9-slim

# 设置工作目录
WORKDIR /app

# 安装系统依赖
RUN apt-get update && apt-get install -y \
    gcc \
    g++ \
    git \
    && rm -rf /var/lib/apt/lists/*

# 复制依赖文件
COPY requirements.txt .

# 安装 Python 依赖
RUN pip install --no-cache-dir -r requirements.txt

# 复制项目文件
COPY . .

# 创建必要的目录
RUN mkdir -p temp data

# 设置环境变量
ENV FLASK_APP=app.py
ENV FLASK_ENV=production
ENV PORT=5000

# 暴露端口
EXPOSE 5000

# 启动命令
CMD ["python", "app.py"]
```

### 2.3 创建 Docker Compose 文件

```yaml
version: '3.8'

services:
  medical-agent:
    build:
      context: .
      dockerfile: Dockerfile
    image: medical-report-agent:latest
    container_name: medical-report-agent
    ports:
      - "5000:5000"
    environment:
      - OPENAI_API_KEY=${OPENAI_API_KEY}
      - MODEL=glm-5v-turbo
      - BASE_URL=https://open.bigmodel.cn/api/paas/v4/
      - TEMPERATURE=0.7
      - USE_LOCAL_MODEL=false
      - LORA_PATH=./lora_medical_terms
      - ENABLE_PLANNING=true
    volumes:
      - ./temp:/app/temp
      - ./data:/app/data
    restart: unless-stopped
    networks:
      - medical-agent-network

networks:
  medical-agent-network:
    driver: bridge
```

### 2.4 带 GPU 支持的 Docker Compose（用于 LoRA 训练）

```yaml
version: '3.8'

services:
  medical-agent-gpu:
    build:
      context: .
      dockerfile: Dockerfile.gpu
    image: medical-report-agent:gpu
    container_name: medical-report-agent-gpu
    ports:
      - "5000:5000"
    environment:
      - OPENAI_API_KEY=${OPENAI_API_KEY}
      - MODEL=glm-5v-turbo
      - BASE_URL=https://open.bigmodel.cn/api/paas/v4/
      - USE_LOCAL_MODEL=true
      - LORA_PATH=./lora_medical_terms
    volumes:
      - ./temp:/app/temp
      - ./data:/app/data
      - ./lora_medical_terms:/app/lora_medical_terms
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: 1
              capabilities: [gpu]
    restart: unless-stopped
```

### 2.5 创建 GPU 版本 Dockerfile

```dockerfile
# 使用 NVIDIA CUDA 基础镜像
FROM nvidia/cuda:12.1.0-cudnn8-runtime-ubuntu22.04

# 安装 Python 3.9
RUN apt-get update && apt-get install -y \
    python3.9 \
    python3.9-dev \
    python3-pip \
    gcc \
    g++ \
    git \
    && rm -rf /var/lib/apt/lists/*

# 设置 Python 版本
RUN update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.9 1
RUN update-alternatives --install /usr/bin/python python /usr/bin/python3.9 1

# 设置工作目录
WORKDIR /app

# 复制依赖文件
COPY requirements.txt .

# 安装 PyTorch 和其他依赖（带 CUDA 支持）
RUN pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
RUN pip3 install --no-cache-dir -r requirements.txt

# 复制项目文件
COPY . .

# 创建必要的目录
RUN mkdir -p temp data lora_medical_terms

# 设置环境变量
ENV FLASK_APP=app.py
ENV FLASK_ENV=production
ENV PORT=5000
ENV CUDA_VISIBLE_DEVICES=0

# 暴露端口
EXPOSE 5000

# 启动命令
CMD ["python", "app.py"]
```

### 2.6 部署步骤

#### 步骤 1：创建环境变量文件

```bash
# 创建 .env 文件
cat > .env << EOF
OPENAI_API_KEY=your-api-key-here
MODEL=glm-5v-turbo
BASE_URL=https://open.bigmodel.cn/api/paas/v4/
TEMPERATURE=0.7
USE_LOCAL_MODEL=false
LORA_PATH=./lora_medical_terms
ENABLE_PLANNING=true
EOF
```

#### 步骤 2：构建并启动容器

```bash
# CPU 版本
docker-compose up -d

# 或 GPU 版本（需安装 NVIDIA Docker）
docker-compose -f docker-compose.gpu.yml up -d
```

#### 步骤 3：验证部署

```bash
# 查看容器状态
docker ps

# 查看日志
docker logs medical-report-agent

# 测试服务
curl http://localhost:5000
```

## 4. 生产环境部署建议

### 4.1 使用 Gunicorn + Nginx

#### 4.1.1 安装 Gunicorn

```bash
pip install gunicorn
```

#### 4.1.2 创建启动脚本

```bash
#!/bin/bash
cd /path/to/agent-assistant
source venv/bin/activate
gunicorn -w 4 -b 0.0.0.0:5000 app:app --timeout 120
```

#### 4.1.3 Nginx 配置

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 120s;
    }

    location /static {
        alias /path/to/agent-assistant/frontend;
    }
}
```

### 4.2 进程管理（使用 systemd）

创建 `/etc/systemd/system/medical-agent.service`：

```ini
[Unit]
Description=Medical Report Agent Service
After=network.target

[Service]
User=www-data
WorkingDirectory=/path/to/agent-assistant
Environment="PATH=/path/to/agent-assistant/venv/bin"
ExecStart=/path/to/agent-assistant/venv/bin/gunicorn -w 4 -b 127.0.0.1:5000 app:app --timeout 120
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
systemctl daemon-reload
systemctl enable medical-agent
systemctl start medical-agent
```

## 5. LoRA 微调部署

```bash
# 使用 CPU 训练（较慢）
python train_lora_medical_terms.py
```

## 6. 环境变量配置说明

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| OPENAI_API_KEY | 智谱 API Key | 无 |
| MODEL | 模型名称 | glm-5v-turbo |
| BASE_URL | API 基础地址 | https://open.bigmodel.cn/api/paas/v4/ |
| TEMPERATURE | 温度参数 | 0.7 |
| USE_LOCAL_MODEL | 是否使用本地 LoRA 模型 | false |
| LORA_PATH | LoRA 模型路径 | ./lora_medical_terms |
| ENABLE_PLANNING | 是否启用自主规划 | true |
| MAX_HISTORY_LENGTH | 对话历史最大长度 | 20 |
| PORT | 服务端口 | 5000 |

## 7. 常见问题与解决方案

### 问题 1：Docker 构建失败 - 网络超时

**解决方案**：

```bash
# 使用国内镜像源
docker build --build-arg http_proxy=http://proxy.example.com:8080 .

# 或修改 Dockerfile 使用国内 pip 源
RUN pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
```

### 问题 2：GPU 容器无法启动

**解决方案**：

```bash
# 检查 NVIDIA Docker 是否安装正确
docker run --rm --gpus all nvidia/cuda:12.1.0-cudnn8-runtime-ubuntu22.04 nvidia-smi

# 确保 NVIDIA 驱动版本与 CUDA 版本兼容
```

### 问题 3：API 调用失败 403/401

**解决方案**：

```bash
# 检查 API Key 是否正确
cat .env | grep OPENAI_API_KEY

# 确认网络可访问智谱 API
curl -I https://open.bigmodel.cn/api/paas/v4/
```

### 问题 4：LoRA 训练显存不足

**解决方案**：

```bash
# 使用更小的模型
# 修改 train_lora_medical_terms.py 中的模型名称
model_name = "THUDM/glm-4-6b-chat"

# 减小 batch_size
training_args.per_device_train_batch_size = 1

# 启用梯度累积
training_args.gradient_accumulation_steps = 4
```

## 8. 安全建议

1. **API Key 保护**：不要将 API Key 硬编码到代码中，使用环境变量
2. **HTTPS**：生产环境使用 HTTPS 加密传输
3. **访问控制**：限制 API 访问来源 IP
4. **日志审计**：记录关键操作日志
5. **定期更新**：定期更新依赖包和模型版本
