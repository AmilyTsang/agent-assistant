# Agent-Assistant 项目结构说明

## 一、项目整体架构

```
agent-assistant/                              # 项目根目录
├── data/                                    # 数据集目录
├── huatuo_data/                             # Huatuo医学数据集
├── models/                                  # 模型文件目录
├── md/                                      # 文档目录
├── frontend/                                # 前端页面
├── __pycache__/                             # Python编译缓存
├── .idea/                                   # IDE配置（PyCharm）
├── .env                                     # 环境变量配置
├── .env.example                             # 环境变量示例
├── app.py                                   # Flask后端服务入口
├── main.py                                  # 主程序入口
├── train_lora_medical_terms.py              # LoRA微调训练脚本
├── lora_inference.py                        # LoRA推理脚本
├── medical_terms_inference.py               # 医疗术语推理脚本
├── vector_store.py                          # 向量存储管理模块

├── download_qwen2.py                        # Qwen2模型下载脚本
├── download_with_cli.py                     # CLI方式下载脚本
├── download_glm4.py                         # GLM-4模型下载脚本
├── check_training_ready.py                  # 训练准备检查脚本
├── requirements.txt                         # Python依赖清单
├── Dockerfile                               # Docker配置（CPU）
├── Dockerfile.gpu                           # Docker配置（GPU）
├── docker-compose.yml                       # Docker Compose（CPU）
├── docker-compose.gpu.yml                   # Docker Compose（GPU）
└── README.md                                # 项目说明文档
```

## 二、目录详细说明

### 2.1 data/ - 数据集目录

| 文件/目录                   | 说明        | 大小      | 来源   |
| ----------------------- | --------- | ------- | ---- |
| `medical_finetune.json` | 医疗术语微调数据集 | \~100KB | 项目内置 |

**数据格式：**

```json
{
  "instruction": "解释医疗术语：高血压",
  "input": "",
  "output": "高血压：指动脉血压持续升高..."
}
```

### 2.2 huatuo\_data/ - Huatuo医学数据集

| 数据集名称                                            | 类型     | 文件数 | 说明                    |
| ------------------------------------------------ | ------ | --- | --------------------- |
| `FreedomIntelligence_huatuo_knowledge_graph_qa/` | 知识图谱问答 | 3   | train/test/validation |
| `FreedomIntelligence_huatuo_encyclopedia_qa/`    | 百科问答   | 3   | train/test/validation |
| `FreedomIntelligence_huatuo_consultation_qa/`    | 问诊问答   | 3   | train/test/validation |
| `FreedomIntelligence_huatuo26M-testdatasets/`    | 测试数据集  | 1   | test                  |

### 2.3 models/ - 模型文件目录

| 模型名称                        | 参数规模 | 文件大小  | 来源          |
| --------------------------- | ---- | ----- | ----------- |
| `Qwen_Qwen2.5-3B-Instruct/` | 3B   | \~7GB | HuggingFace |

**模型文件结构：**

```
models/Qwen_Qwen2.5-3B-Instruct/
└── Qwen/Qwen2___5-3B-Instruct/
    ├── config.json                    # 模型配置
    ├── tokenizer.json                 # 分词器配置
    ├── tokenizer_config.json          # 分词器参数
    ├── generation_config.json         # 生成配置
    ├── model.safetensors.index.json   # 权重索引
    ├── model-00001-of-00002.safetensors  # 权重文件1 (~3.7GB)
    ├── model-00002-of-00002.safetensors  # 权重文件2 (~3.7GB)
    ├── vocab.json                     # 词表
    ├── merges.txt                     # BPE合并规则
    ├── LICENSE                        # 许可证
    └── README.md                      # 模型说明
```

## 三、核心代码文件说明

### 3.1 服务端文件

| 文件        | 功能        | 主要类/函数                                           |
| --------- | --------- | ------------------------------------------------ |
| `app.py`  | Flask后端服务 | `MedicalReportAgent`, `/api/chat`, `/api/upload` |
| `main.py` | 命令行入口     | `main()`                                         |

### 3.2 训练相关文件

| 文件                            | 功能         | 用途           |
| ----------------------------- | ---------- | ------------ |
| `train_lora_medical_terms.py` | LoRA微调训练脚本 | 医疗术语模型训练     |
| `lora_inference.py`           | LoRA推理脚本   | 加载LoRA模型进行推理 |
| `medical_terms_inference.py`  | 医疗术语推理     | 专用医疗术语解释     |

### 3.3 核心模块

| 文件                   | 功能     | 依赖                  |
| -------------------- | ------ | ------------------- |
| `vector_store.py`    | 向量存储管理 | FAISS, scikit-learn |
| `document_parser.py` | 文档解析   | PyPDF2, python-docx |
| `tools.py`           | 工具定义   | langchain           |

### 3.4 数据下载脚本

| 文件                       | 功能          | 特点                |
| ------------------------ | ----------- | ----------------- |
| `huatuo_datasets.py`     | Huatuo数据集下载 | 支持多数据集            |
| `download_base_model.py` | 基础模型下载      | 支持GLM-4/Qwen2     |
| `download_qwen2.py`      | Qwen2模型下载   | Qwen系列专用          |
| `download_with_cli.py`   | CLI方式下载     | 使用huggingface-cli |

## 四、配置文件说明

### 4.1 .env - 环境变量配置

```env
# API模式配置
OPENAI_API_KEY=your_api_key_here
MODEL=glm-5v-turbo
BASE_URL=https://open.bigmodel.cn/api/paas/v4/

# 本地模式配置
USE_LOCAL_MODEL=false
LORA_PATH=./lora_medical_terms

# 代理配置（可选）
# HTTP_PROXY=http://proxy:port
# HTTPS_PROXY=http://proxy:port
```

### 4.2 requirements.txt - 依赖清单分类

| 类别          | 依赖包                             | 用途         |
| ----------- | ------------------------------- | ---------- |
| 基础框架        | langchain, flask, flask-cors    | 后端框架       |
| 文档处理        | PyPDF2, python-docx             | PDF/Word解析 |
| 向量检索        | faiss-cpu, scikit-learn         | 向量化和检索     |
| LLM相关       | torch, transformers, accelerate | 模型加载和推理    |
| LoRA微调      | peft, datasets, evaluate        | 参数高效微调     |
| 数据处理        | sentencepiece, safetensors      | 分词和权重加载    |
| HuggingFace | huggingface-hub                 | Hub访问和下载   |

## 七、典型工作流程

### 7.1 开发调试流程

```
1. 安装依赖
   pip install -r requirements.txt

2. 配置环境
   复制 .env.example 为 .env
   修改 API_KEY 等配置

3. 启动服务
   python app.py

4. 测试接口
   POST /api/chat
   {"message": "解释高血压"}
```

### 7.2 LoRA微调流程

```
1. 下载基础模型
   python download_base_model.py

2. 检查准备
   python check_training_ready.py

3. 运行训练
   python train_lora_medical_terms.py

4. 测试微调效果
   python lora_inference.py
```

### 7.3 Docker部署流程

```
# CPU部署
docker-compose up -d

# GPU部署
docker-compose -f docker-compose.gpu.yml up -d

# 访问服务
http://localhost:5000
```
