## 二、目录详细说明

### 2.1 data/ - 数据集目录

| 文件/目录                   | 说明        | 大小      | 来源   |
| ----------------------- | --------- | ------- | ---- |
| `medical_finetune.json` | 医疗术语微调数据集 | \~100KB | 项目内置 |

**数据格式：**

```json
{
  "instruction": "解释医疗术语：高血压",
  "input": "",
  "output": "高血压：指动脉血压持续升高..."
}
```

### 2.2 huatuo\_data/ - Huatuo医学数据集

| 数据集名称                                            | 类型     | 文件数 | 说明                    |
| ------------------------------------------------ | ------ | --- | --------------------- |
| `FreedomIntelligence_huatuo_knowledge_graph_qa/` | 知识图谱问答 | 3   | train/test/validation |
| `FreedomIntelligence_huatuo_encyclopedia_qa/`    | 百科问答   | 3   | train/test/validation |
| `FreedomIntelligence_huatuo_consultation_qa/`    | 问诊问答   | 3   | train/test/validation |
| `FreedomIntelligence_huatuo26M-testdatasets/`    | 测试数据集  | 1   | test                  |

### 2.3 models/ - 模型文件目录

| 模型名称                        | 参数规模 | 文件大小  | 来源          | 状态   |
| --------------------------- | ---- | ----- | ----------- | ---- |
| `Qwen_Qwen2.5-3B-Instruct/` | 3B   | \~7GB | HuggingFace | 需下载  |

> **注意**：基础模型文件较大，需通过下载脚本获取。首次使用前请运行下载脚本。

**模型文件结构：**

```

├── tokenizer.json                 # 分词器配置
├── tokenizer_config.json          # 分词器参数
├── generation_config.json         # 生成配置
├── model.safetensors.index.json   # 权重索引

├── model-00002-of-00002.safetensors  # 权重文件2 (~3.7GB)
├── vocab.json                     # 词表
```

### 2.4 lora_medical_sampled/ - LoRA医疗微调模型

| 文件                      | 说明               | 大小    |
| ----------------------- | ---------------- | ----- |
| `adapter_config.json`   | LoRA配置文件        | \~1KB |
| `adapter_model.safetensors` | LoRA权重文件      | \~100MB |
| `tokenizer.json`        | 分词器配置（副本）     | \~2MB  |
| `tokenizer_config.json` | 分词器参数（副本）     | \~1KB |
| `chat_template.jinja`   | 对话模板           | \~1KB |
| `README.md`             | 模型说明           | \~1KB |

**LoRA配置参数：**
- 基础模型：Qwen2.5-3B-Instruct
- r (rank)：8
- lora_alpha：16
- lora_dropout：0.05
- target_modules：o_proj, down_proj, q_proj, gate_proj, k_proj, up_proj, v_proj

## 四、配置文件说明

### 4.1 .env - 环境变量配置

```env
# API模式配置
OPENAI_API_KEY=your_api_key_here
MODEL=glm-5v-turbo
BASE_URL=https://open.bigmodel.cn/api/paas/v4/

# 本地模式配置
USE_LOCAL_MODEL=false
LORA_PATH=./lora_medical_sampled

# 高级配置
ENABLE_PLANNING=true
MAX_HISTORY_LENGTH=20
PORT=5000

# 代理配置（可选）
# HTTP_PROXY=http://proxy:port
# HTTPS_PROXY=http://proxy:port
```

**配置说明：**
| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `OPENAI_API_KEY` | - | API访问密钥（必填，API模式） |
| `MODEL` | glm-5v-turbo | 模型名称 |
| `BASE_URL` | 智谱API地址 | API服务地址 |
| `USE_LOCAL_MODEL` | false | 是否使用本地LoRA模型 |
| `LORA_PATH` | ./lora_medical_sampled | LoRA模型路径 |
| `ENABLE_PLANNING` | true | 是否启用Agent规划能力 |
| `MAX_HISTORY_LENGTH` | 20 | 最大对话历史长度 |
| `PORT` | 5000 | 服务端口 |

### 4.2 requirements.txt - 依赖清单分类

| 类别          | 依赖包                             | 用途         |
| ----------- | ------------------------------- | ---------- |
| 基础框架        | langchain, flask, flask-cors    | 后端框架       |
| 文档处理        | PyPDF2, python-docx             | PDF/Word解析 |
| 向量检索        | faiss-cpu, scikit-learn         | 向量化和检索     |
| LLM相关       | torch, transformers, accelerate | 模型加载和推理    |
| LoRA微调      | peft, datasets, evaluate        | 参数高效微调     |
| 数据处理        | sentencepiece, safetensors      | 分词和权重加载    |
| HuggingFace | huggingface-hub                 | Hub访问和下载   |

## 七、典型工作流程

### 7.1 开发调试流程

```bash
1. 安装依赖
   pip install -r requirements.txt

2. 配置环境
   复制 .env.example 为 .env
   修改 OPENAI_API_KEY 等配置

3. 启动服务（API模式）
   python app.py

4. 启动服务（本地LoRA模式）
   # 需先下载基础模型
   USE_LOCAL_MODEL=true python app.py

5. 测试接口
   POST /api/chat
   {"message": "解释高血压", "model_type": "api"}
```

### 7.2 模型切换

```bash
# 查询可用模型
GET /api/models

# 切换到本地模型
POST /api/switch
{"model_type": "local"}

# 切换到API模型
POST /api/switch
{"model_type": "api"}
```

### 7.3 LoRA微调流程

```bash
1. 下载基础模型（Qwen2.5-3B-Instruct）
   python download_simple.py

2. 检查准备
   python check_training_ready.py

3. 运行训练
   python train_lora_medical_terms.py

4. 微调输出位置
   # 默认输出到 ./lora_medical_sampled/
   # 如需使用其他路径，修改 LORA_PATH 环境变量

5. 测试微调效果
   python lora_inference.py --lora_path ./lora_medical_sampled
```

### 7.4 Docker部署流程

```
# CPU部署
docker-compose up -d

# GPU部署
docker-compose -f docker-compose.gpu.yml up -d

# 访问服务
http://localhost:5000
```
